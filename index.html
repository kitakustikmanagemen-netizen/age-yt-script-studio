🔑 Pengaturan API Key

API key Gemini kamu disimpan hanya di browser ini (localStorage), tidak pernah dikirim ke server pihak ketiga selain langsung ke Google lewat Worker proxy milikmu sendiri. Bisa tambah lebih dari 1 key — kalau satu kena limit, otomatis pindah ke key berikutnya.

Alamat Cloudflare Worker hasil deploy kamu, contoh: https://age-yt-proxy.namamu.workers.dev
